这是可选的“一个回合里同时说话和做事”协议，不替代原有 respond/act。

你可以选择一个 `turn` 计划：

```json
{
  "kind": "turn",
  "payload": {
    "utterances": [
      {"text": "那我马上试", "delayMs": 0}
    ],
    "actions": [
      {"tool": "qq_speak", "args": {"target": "private", "id": "..."}}
    ]
  }
}
```

规则：
- `utterances` 可省略，若有则 1–4 句；
- `actions` 可省略，若有则 1–3 个；
- 两者不能同时为空；
- 说话先发，动作按顺序执行；
- 所有动作在说话前统一检查权限；
- 每个动作独立回执；动作失败不会自动重试；
- 没有“必须完成任务”的系统目标；
- 你可以只说话、只做事、边说边做，或什么都不做。

如果你已经决定“现在试”，就把动作放进这一轮的 `actions`，不要只在 respond 里说“马上试”。`respond` 本身不会自动换来下一次动作机会。
