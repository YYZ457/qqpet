怎么接？（只需要做一次）
  1. QQ 传输程序 SnowLuma 不能由本包代为分发（它的协议不允许），请自己到官方页面下载： github.com/SnowLuma/SnowLuma/releases，下载 Windows 完整包并解压到任意位置。
  2. 按它自己的说明启动（Windows 运行它的 launcher.bat），打开它的管理页，登录 QQ，并添加 OneBot 连接： WebSocket 服务端 端口 3001、HTTP 服务端 端口 3000（默认值，不用改本包任何东西）。
  3. 回到这里，上面状态变成“已连接”就好了。之后她会收到 QQ 里的私聊和群消息，并回复。
  4. 如果你的端口或令牌不一样：在 data 文件夹里新建 qq.json，内容如 {"ws":"ws://127.0.0.1:3001/","http":"http://127.0.0.1:3000","token":""}，重启即可。
提醒：用非官方协议工具登录 QQ 有账号被限制的风险，SnowLuma 的 EULA 也写明风险自负；建议先用小号试。
